User Guide: How to Use Stock Manager TT

Welcome to Stock Manager TT, a simple and powerful tool designed for small businesses in Trinidad and Tobago to manage inventory efficiently.

1. Dashboard Overview

When you open the app, you’ll see:

  • A navigation bar with links to blog, guides, FAQs, etc.
  • A settings panel where you can set your low stock threshold.
  • An actions toolbar with buttons to:
    • Undo last change
    • Clear product list
    • Show low stock only
    • Export or import data
  • A search bar to find products by name or barcode
  • A form to add new products
  • A table listing all products with columns:
    • Product Name
    • Supplier
    • Barcode
    • Quantity
    • Unit Price
    • Total Value
    • Last Updated
    • Action (Delete)

2. Adding New Products

To add a new product:

  1. Fill in the form fields:
    • Product Name: e.g., "Cornflakes"
    • Barcode: unique number identifying the item
    • Quantity: number of units in stock
    • Price: cost per unit
    • Supplier: choose from dropdown or add a new one
  2. Click the "Add Product" button.

Note: Make sure to fill out all fields, especially supplier, to avoid errors.

3. Managing Suppliers

You can easily add or manage suppliers:

  1. Type the supplier’s name into the input field under “Add Supplier”
  2. Click the "Add Supplier" button

Note: Duplicate supplier names are not allowed.

4. Searching for Products

Use the search bar at the top to quickly find products by:

  • Product name
  • Supplier name
  • Barcode

The table updates in real time as you type.

5. Tracking Low Stock Items

To filter and view products that are running low on stock:

  1. Set your desired low stock threshold using the input box under "Low Stock Warning"
  2. Click "Show Low Stock" to display only those items

Example: If you set the threshold to 25, any product with 25 or fewer units will show up.

6. Exporting Inventory Data

You can export your current inventory as a CSV file:

  1. Click the "Export to CSV" button
  2. Your browser will download a file named stock-export.csv

This file includes:

  • Product Name
  • Supplier
  • Barcode
  • Quantity
  • Price
  • Total Value
  • Last Updated
  • Grand Total value of all stock

7. Importing Inventory Data

If you have an existing inventory list in a CSV or Excel file, you can import it:

  1. Click the "Import from CSV" button
  2. Select your .csv or .xlsx file
  3. The app will read and add the products to your inventory

Supported formats:

  • Trinidad-style CSV (no dollar signs, lowercase headers)
  • Stock-export style (quoted fields, dollar signs, extra column)

Note: Duplicates based on barcode will be skipped automatically.

8. Undoing Changes

The app keeps a history of your changes:

  • Undo Last Change: Reverts to the previous version of your product list
  • Undo Last Import: Restores your data to what it was before the most recent import
  • Clear All Products: Removes everything (a backup is saved)

Warning: These actions cannot be undone once confirmed.

9. Resetting the App

If you want to start fresh:

  1. Click "Reset App"
  2. Confirm that you want to delete all data

This removes all products, suppliers, settings, and backups — use carefully!

10. Understanding the Table

Each row represents a product in your inventory:

Column Description
Product Name of the item
Supplier Who supplies the product
Barcode Unique ID for the product
Quantity How many units are in stock
Unit Price Cost per unit
Total Value Calculated as Quantity × Price
Last Updated When the product info was last changed
Action Button to delete the product

You can edit quantity and price directly in the table.

11. Tips for Best Use

  • Keep your supplier list updated to track where products come from
  • Regularly check for low stock items to avoid running out
  • Use the export feature to back up your data or generate reports
  • Import data to quickly update large batches of products
  • Always double-check imported files for duplicates or formatting issues
